## Field Note

Zuken CADSTAR is easier to trust when the board stays smaller than the product it came from. A named session shows which design is active, the pins show which nets you will route today, and the closing note tells the next person which schematic capture drives the copper. That record is short on purpose: not a copy of every footprint, only the path back to the board that is still open.

The same loop fits a student schematic, a client PCB, or a computer shared by two designers. Open the last Zuken CADSTAR session, confirm one net, and leave the traces easier to find than you found them. Drawings stay where they are. Zuken CADSTAR only holds the schematic capture, the PCB layout, and the handoff.

## One Real Pass

Pick a board that already has a name: a small power supply, a sensor card, or a short interface. Open it in Zuken CADSTAR, keep only those footprints and nets on the board, and read one routed net you can point to. A pass is done when that net is tied to schematic capture and the unused parts are no longer in the way. Zuken CADSTAR does not need a full rebuild of the copper before it is useful.

If the pass feels crowded, the layout is too wide. Drop anything that belongs to a different board and leave it out of this workspace. The next pass can have its own title. What matters is that this one stays readable from the first footprint to the last trace, with the summary still matching the PCB layout on the board.
